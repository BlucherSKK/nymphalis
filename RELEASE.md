# Nymphalis

## Изменения

- теперь при загрузке манги в указанную папку загружается ещё и обложка манги

## Установка

Скачай бинарник для своей платформы ниже и положи в `$PATH`:

```sh
chmod +x nymphalis-linux-amd64
sudo mv nymphalis-linux-amd64 /usr/local/bin/nymphalis
```

пока что только для arch linux можно одной командой

```sh
paru -Sy nymphalis-bin
```

или

```sh
yay -Sy nymphalis-bin
```
